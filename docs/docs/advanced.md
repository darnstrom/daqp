Beyond standard convex QPs, DAQP supports mixed-integer QPs, hierarchical QPs, affine variational
inequalities, and QPs with soft constraints, which are accessed through the same interface as regular
QPs by supplying additional arguments. Multistage problems, as in optimal control, have a structure-exploiting solver with its own interface.
